# sdwire

Go SDK + CLI for SDWire USB SD-card multiplexers. Fork of github.com/fcjr/sdwire.

## Conventions

- **Conventional commit messages**: prefix every commit with a type — `feat:`, `fix:`, `chore:`, `refactor:`, `docs:`, `test:`, etc.
- Work is tracked with beans (run `beans prime` for usage); include bean file changes in the same commit as the code they describe.
